# Project Echo Skills

Agent skills for operating Project Echo as a product-feedback workspace: analyze requests, create feedback, draft changelogs, and work through MCP.

## Install

```bash
npx skills add justin-butlion/project-echo-skills --skill project-echo-product-manager
```

## Docs

- [Install the agent skill](https://docs.projectecho.io/api-mcp-and-embed/agent-skill)
- [Connect MCP](https://docs.projectecho.io/api-mcp-and-embed/connect-mcp)
- [Create API keys](https://docs.projectecho.io/api-mcp-and-embed/create-manage-api-keys)

## Repository

Skills live under `skills/<skill-name>/` with a `SKILL.md` (Agent Skills / [agentskills.io](https://agentskills.io) format).
